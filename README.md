# 🍽️ 기후 식탁 (Climate Table)

**날씨가 바꾸는 우리 밥상 — 기후플레이션 학습 시뮬레이터**

기상·기후 AI 해커톤(기상청, 2026) 출품작.
폭염·가뭄·호우·냉해 시나리오를 슬라이더로 조절하면, 백엔드의 회귀모델이 배추·사과·쌀 등 농산물 가격을 실시간 예측합니다. "기후변화가 위험하다"는 추상적 경고를 **"내 장바구니가 얼마나 오르는가"**라는 체감으로 바꾸는 교육 도구입니다.

![preview](docs/preview.png)

## ▶ 실행 방법

외부 패키지·설치가 **전혀 필요 없습니다** (Python 표준 라이브러리만 사용).

```bash
python backend/app.py
# → http://localhost:8000 접속
```

Python 3.8+ 면 충분합니다. (개발·검증: Python 3.11)

## 🎮 사용법

| 기능 | 방법 |
|---|---|
| 작물 선택 | 배추·무·사과·쌀·시금치·양파 6종 |
| 날씨 시나리오 | 폭염·호우·가뭄·한파·개화기냉해 슬라이더 조절 |
| 프리셋 | 2024 폭염·2020 장마·2023 냉해(금사과)·한파·평년 |
| 결과 | 예측 가격 + 같은 시기 평년 기상 대비 % + 가격 기여 요인 |
| 차트 | 2018~2025 실제 가격 추이 + 기상 사건 표시 + 현재 예측선 |
| 학습 | 기상-가격 상관, 적응·해결방안, 🎓 퀴즈 |

## 🧩 아키텍처 (프론트엔드 + 백엔드)

```
[브라우저] frontend/ — Vanilla JS + Canvas 차트 (CDN 의존 0)
    │  fetch /api/*
    ▼
[백엔드] backend/app.py — Python http.server (표준 라이브러리만)
    ├─ GET  /api/health  /items  /series  /correlate  /model  /quiz
    ├─ POST /api/simulate  (시나리오 → 예측·기여·해설·적응전략)
    └─ backend/model.py — 순수 파이썬 릿지 회귀 (학습·예측·상관·신뢰도)
[데이터] backend/data/dataset.json (2018~2025 월별)
         backend/data/gen_data.py (데이터 생성기)
```

## 🧪 작동 원리 (교육용 모델)

- **회귀모델**: 월별 기상 피처(폭염일수·한파일수·호우일수·가뭄지수·개화기냉해·일조)로 작물 가격을 학습하는 릿지 선형회귀(순수 파이썬, 정규방정식).
- **날씨 효과 분리**: 예측을 **'같은 시기 평년 기상'** 기준과 비교해, 계절 효과를 제거하고 **날씨가 만든 가격 변동**만 보여줍니다.
- **신뢰도(R²) 공개**: 작물별 설명력을 높음/보통/낮음으로 표기. 예) 쌀은 낮음 — 정부 비축·수급관리로 기상 영향이 작음(교육 포인트).
- **재현 사례**: 폭염·가뭄 → 배추 급등 / 봄 개화기 냉해 → 사과('금사과') 상승.

> 정밀 시세 예측이 아니라, 기상→작황→가격의 **인과를 정성적으로 정확하게** 체감시키는 학습용 모델입니다.

## 📊 데이터 출처

월별 데이터셋은 **기상청 기상자료개방포털(data.kma.go.kr)·KAMIS(농산물유통정보)·통계청** 보도값과 실제 기후사건(2018 폭염, 2020 최장 장마, 2022 집중호우, 2023 냉해·2024 금사과, 2024 폭염)에 **실제 도매가 수치로 보정**한 교육용 모델입니다.

> **실제 데이터 대조 검증**: 모델의 평년가·사건 절대가격이 실제와 일치함을 확인했습니다. 예) 배추 폭염 예측 3,950원/kg = 실제 도매 3,594~4,150원/kg, 사과 금사과 예측 6,910원/kg = 실제 5,141~7,767원/kg. 상세·출처는 [`docs/검증-실제데이터대조.md`](docs/검증-실제데이터대조.md) 참고.

본선 단계에서 기상청·KAMIS OpenAPI 실데이터 연동으로 전 시계열을 실측값으로 교체할 예정입니다.
