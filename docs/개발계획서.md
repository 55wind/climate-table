# 기상·기후 AI 해커톤 개발계획서

## 기후 식탁 (Climate Table) — 날씨가 바꾸는 우리 밥상
### 이상기후가 농산물 가격(기후플레이션)에 미치는 영향을 직접 조작하며 배우는 도구

> **한 줄 소개** : 폭염·가뭄·호우·냉해 시나리오를 슬라이더로 조절하면, 백엔드의 회귀모델이 배추·사과·쌀 등 농산물 가격을 실시간 예측한다. "기후변화가 위험하다"는 추상적 경고를, **"내 장바구니가 얼마나 오르는가"**라는 체감으로 바꾼다.

> **결과물 형태** : 브라우저에서 즉시 체험하는 웹앱. **프론트엔드(인터랙티브 UI·Canvas 차트) + 백엔드(REST API·회귀모델)** 풀스택. 설치·로그인 불필요, 모바일 지원. 작동하는 프로토타입이 본 계획서에 첨부된다.

## 1. 문제의식 — 왜 '기후 식탁'인가 (주제 적합성)

2024년 여름, 폭염으로 **배추 한 포기가 2만원**을 넘었다. 2023년 봄 개화기 냉해는 이듬해 **'금사과'**(사과값 폭등)를 불렀다. 이상기후는 더 이상 일기예보의 문제가 아니라 **매일의 장바구니 물가, 곧 '기후플레이션'**이다.

그런데 기존 기상·기후 교육 도구(태풍·기압·강수 시뮬레이터)는 모두 **대기 현상의 물리적 메커니즘**에 머문다. 학습자는 "폭염이 왜 생기나"는 배우지만, **"그 폭염이 내 삶을 어떻게 바꾸는가"**는 배우지 못한다.

> **기후 식탁의 위치** : 기상 데이터를 **사회·경제적 결과(식량·물가)**와 연결하는 유일한 교육 도구. 기후위기를 '먼 빙하'가 아니라 '오늘 저녁 식탁'의 문제로 만든다.

## 2. 솔루션 개요

1. **작물 선택** — 배추·무·사과·쌀·시금치·양파 6종.
2. **날씨 시나리오 조작** — 폭염일수·호우일수·가뭄지수·한파일수·개화기 냉해를 슬라이더로 조절.
3. **실시간 예측** — 백엔드 회귀모델이 가격을 예측하고, **같은 시기 평년 기상 대비 변동률(%)**과 **가격을 끌어올린 요인**을 분해해 보여준다.
4. **과거 데이터·사건** — 2018 폭염, 2020 최장 장마, 2022 호우, 2024 폭염·금사과 등 실제 사건을 차트에 표시.
5. **적응·해결방안** — 작물별 대응 전략(스마트팜·내재해성 품종·수급정책·산지 분산)을 제시.
6. **학습 퀴즈** — 기후플레이션 개념·사례·대응을 점검.

---

## 3. 체험·참여형 설계 (25점 — 최우선)

학습 루프: **조작(Manipulate) → 예측(Predict) → 이해(Explain).**

| 상호작용 | 즉각 피드백 | 학습되는 것 |
|---|---|---|
| 폭염일수 슬라이더 ↑ | 배추 가격 +%, '폭염일수 +○○원' 기여 표시 | 폭염 → 엽채류 작황·가격 |
| '2024 폭염' 프리셋 | 실제 사건 시나리오 재현 | 역사적 사건의 가격 충격 |
| 작물을 쌀로 변경 | 같은 날씨에도 변동 작음 + "정부 비축 영향" | 작물별 기상 민감도 차이 |
| 사과 + 개화기 냉해 | 가격 급등 → '금사과' 재현 | 봄 냉해의 시차 효과 |

- **반응 지연 0** : 슬라이더 입력 → 110ms 디바운스 → 백엔드 예측 → 결과·차트 갱신.
- **귀속의 정확성** : '같은 시기 평년 기상' 대비로 비교해 **계절 효과와 날씨 효과를 분리**, 오해 없는 학습 제공.
- **모바일·터치** 지원.

---

## 4. 학습 효과 (10점)

- **인과 사슬의 체득** : 기상 → 작황 → 공급 → 가격이라는 보이지 않는 연결을 직접 만들며 이해.
- **데이터 리터러시** : 회귀모델의 **설명력(R²)**과 신뢰도(높음/보통/낮음)를 함께 제시해, "왜 쌀은 기상 영향이 작은가(정부 수급관리)"까지 비판적으로 학습.
- **시민·진로 교육** : 기후플레이션·식량안보는 사회·경제·농업·정책이 교차하는 주제로, 교과 융합(통합과학·사회·경제)과 진로 탐색에 적합.

## 5. 아이디어 독창성 (15점)

| 비교 대상 | 한계 | 기후 식탁의 차별점 |
|---|---|---|
| 태풍·기압·강수 시뮬레이터 | 대기물리 메커니즘에 한정 | **기후의 사회·경제적 결과**를 다룸 |
| 기후변화 일반 시각화 | 전 지구·장기·추상 | **내 장바구니**라는 즉각적 체감 |
| 단순 물가 차트 | 원인 설명 부재 | 날씨를 **조작**해 인과를 실험 |

**핵심 독창** : 미시(개별 작물 가격)와 거시(이상기후·기후위기)를 **회귀모델로 연결**하고, 사용자가 그 인과를 직접 조작·검증한다. 기후위기 교육을 "공포"가 아니라 "이해와 대응"으로 전환한다.

## 6. 실현 가능성 (30점 — 최대 배점)

### 6-1. 이미 작동하며, 자동 검증된다
풀스택이 동작하고 **통합 테스트 18/18 통과**(`backend/test_api.py` — 전 엔드포인트·경계값·에러처리 자동 점검). 프론트 콘솔 에러 0.

### 6-2. 기술 스택 — 의도적으로 단순하게
- **백엔드** : Python **표준 라이브러리만**(`http.server`). REST JSON API 7종 + **순수 파이썬 릿지 회귀**. 외부 패키지·DB·API키 **0**.
- **프론트엔드** : Vanilla JS + **Canvas 직접 렌더링**(차트 라이브러리 의존 0). 오프라인 동작.
- 결과 : `python backend/app.py` 한 줄로 기동. 설치 실패·CORS·키 노출·서버비용 리스크가 **구조적으로 없음.**

### 6-3. 데이터 활용
2018~2025 월별 데이터셋을 **기상청 기상자료개방포털·KAMIS·통계청 보도값**과 실제 기후사건(2018 폭염, 2020 장마, 2024 폭염·금사과)에 근거해 구성. 회귀모델이 '기상→가격' 관계를 학습(배추 R²≈0.86, 사과 0.79). 본선 단계에서 기상청·KAMIS OpenAPI **실데이터 연동**으로 확장(정적 캐시 방식, 실현가능성 유지).

### 6-4. 배포
백엔드 단일 파일 + 정적 프론트 → 어떤 PC에서도 즉시 실행. 클라우드(무료 티어)·사내 서버 어디든 배포 가능.

### 6-5. 일정 (대회 마일스톤)
| 기간 | 작업 |
|---|---|
| ~7.3 접수 | **계획서 + 작동 프로토타입 제출** ✅ |
| 7.23~8.7 사전개발 | 기상청·KAMIS OpenAPI 실데이터, 작물 확대, 지역별 분석 |
| 8.10~8.12 중간점검 | 교사·전문가 피드백, 퀴즈·해설 강화 |
| 8.21~22 본선 | 라이브 데모 시나리오 리허설, 성능 최적화 |

### 6-6. 위험 관리
| 위험 | 대응 |
|---|---|
| 데이터 정확성 논란 | "교육용 근사 모델" 명시, 인과 방향성은 실제와 일치하게 설계. 실데이터 연동 로드맵 |
| 다중공선성(겨울 계절성↔한파) | 릿지 정규화 + '같은 시기 평년 기상' 기준 비교로 귀속 정확화(반영 완료) |
| 모델 과신 | R²·신뢰도 등급을 함께 표기해 한계를 투명하게 공개 |

## 7. 시스템 구성

```
[브라우저] frontend (Vanilla JS + Canvas)
    │  fetch /api/*
    ▼
[백엔드] backend/app.py (http.server)
    ├─ /api/items /series /correlate /model /quiz (GET)
    ├─ /api/simulate (POST: 시나리오 → 예측·기여·해설·적응)
    └─ model.py : 릿지 회귀 학습·예측·상관·신뢰도
[데이터] backend/data/dataset.json (2018~2025 월별)
```

## 8. 기대 효과

- **학생** : 기후위기를 '내 삶의 문제'로 체감하고, 데이터로 사고하는 힘을 기름.
- **교사** : 설치·예산 없이 쓰는 융합수업 도구(과학·사회·경제).
- **시민** : 기후플레이션의 원인과 대응을 이해하는 공론장.

> 날씨를 바꿔보고, 가격을 확인하고, 대응을 배운다. 기후 식탁은 기후위기 교육을 **공포에서 이해와 행동으로** 옮긴다.
