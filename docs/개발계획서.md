# 기상·기후 AI 해커톤 개발계획서

## 날씨 샌드박스 (Weather Sandbox Korea)
### — 기압을 직접 움직여 한반도 날씨를 만드는 인터랙티브 학습 도구

> **한 줄 소개** : 학습자가 고기압·저기압을 손으로 끌어다 놓으면, 기압경도력과 전향력으로 계산된 바람장을 따라 수천 개의 입자가 실시간으로 흐른다. "읽는 기상학"이 아니라 "조작하는 기상학"을 브라우저에서 즉시 체험한다.

> **결과물 형태** : 설치·로그인 없이 브라우저에서 바로 열리는 웹앱(단일 페이지, 정적 호스팅). PC·태블릿·모바일 모두 지원. **이미 작동하는 프로토타입이 본 계획서에 첨부되어 있다.**

## 1. 문제의식 — 왜 이 도구인가 (주제 적합성)

기상·기후 교육의 가장 큰 벽은 **눈에 보이지 않는 힘을 다룬다**는 점이다. 기압, 전향력, 기단의 충돌은 교과서의 화살표 그림과 정적인 일기도로만 제시된다. 학습자는 "저기압은 반시계방향"을 **외울 수는 있어도 이유를 체감하지 못한다.**

기존 명품 사이트들도 이 간극을 완전히 메우지 못한다.
- **earth.nullschool / Windy** : 시각화는 최고지만 "관측 결과를 보여줄 뿐", 학습자가 원인을 **바꿔볼 수 없다.**
- **PhET / En-ROADS** : 조작 학습의 정석이지만 한반도 맥락·실제 일기도 표기가 없다.

> **본 작품의 위치** : "보여주는 시각화"와 "조작하는 시뮬레이터"의 교집합. 그리고 **한반도·우리나라 교육과정**에 정조준.

다루는 개념: 기압경도력 · 전향력(코리올리) · 지균풍 · 고기압/저기압의 발산·수렴 · 기단과 전선(장마전선) · 태풍의 구조 · 계절별 한반도 기압배치 · **기후변화가 이 모든 것을 어떻게 바꾸는가.**

## 2. 솔루션 개요

한반도 지도 위에서 다음을 할 수 있다.

1. **실제 날씨 불러오기** — 한여름(북태평양고기압) / 장마(정체전선) / 한겨울(삼한사온) / 태풍 북상 / 봄(이동성고기압) 5종 프리셋. 실제 계절 기압배치를 모델링한 시작점.
2. **직접 만들기** — 고기압·저기압을 지도에 놓고 드래그로 이동, 강도·크기·기단 기온을 슬라이더로 조절.
3. **즉시 관찰** — 바람 입자 흐름, 등압선(일기도), 기온 분포(색), 강수·전선대가 조작에 **실시간 반응.**
4. **지구온난화 실험** — 슬라이더로 온난화 강도를 올리면 북태평양고기압이 확장·강화되고 기온이 상승. **폭염위험·강수강도·최대풍속 지표**가 숫자로 변한다.
5. **학습 강화** — 조작 맥락에 맞춰 바뀌는 설명 카드 + 5문항 개념 퀴즈.

## 3. 체험·참여형 설계 (25점 — 최우선 설계축)

핵심 학습 루프: **조작(Manipulate) → 관찰(Observe) → 설명(Explain).**

| 상호작용 | 즉각 피드백 | 학습되는 원리 |
|---|---|---|
| 저기압을 놓는다 | 입자가 반시계로 빨려든다 | 저기압=수렴·상승·흐림/비 |
| 두 시스템을 가까이 붙인다 | 등압선이 촘촘해지고 바람이 빨라진다 | 기압경도력 ∝ 등압선 밀도 |
| 남쪽 더운 고기압 + 북쪽 찬 고기압 | 경계에 강수대(장마전선) 생성 | 기단 충돌 → 전선 → 강수 |
| 태풍 중심 기압을 낮춘다 | 풍속이 급증(빨간 입자) | 중심기압↓ → 강풍 |
| 온난화 슬라이더 ↑ | 폭염지수·강수강도 상승 | 기후변화의 정량적 영향 |

- **반응 지연 0** : 조작 즉시 기압장·바람장 재계산, 입자는 매 프레임 이류.
- **다중 입력** : 마우스·터치 모두 지원(드래그/슬라이더), 모바일 한 손 조작 가능.
- **부담 없는 진입** : 첫 화면부터 살아 움직이는 한여름 장면 → "내가 뭘 하는 곳인지" 즉시 이해.

물리적 정확성: 바람은 **지균풍(기압경도력 + 전향력) + 마찰 유입각**으로 계산한다. 북반구 저기압=반시계 수렴, 고기압=시계 발산이 식에서 자연히 도출되며, 전향력은 위도(sin φ)에 의존시켜 한반도 위도대에서 사실적으로 동작한다. 풍속은 현실 최대치(~65 m/s)로 상한 처리.

## 4. 학습 효과 (10점) — 교육과정 연계

대한민국 **2022 개정 교육과정** 직접 연계:

- **중학교 과학 3학년** : 「기권과 날씨」 — 기압과 바람, 기단과 전선, 우리나라의 계절별 날씨
- **통합과학** : 「환경과 에너지」 — 지구온난화와 기후변화
- **지구과학Ⅰ** : 대기의 운동과 순환, 우리나라의 주요 악기상(태풍·장마·한파)

학습 목표(예시):
1. 고기압·저기압 주변 바람의 방향과 그 원인(전향력)을 **설명할 수 있다.**
2. 계절별 한반도에 영향을 주는 기단을 구분하고 날씨 특징을 **예측할 수 있다.**
3. 기후변화가 폭염·태풍·강수에 미치는 영향을 **정량적 지표로 해석할 수 있다.**

교사용 활용: 프리셋 5종 = 수업 5차시 시나리오. 퀴즈는 형성평가로 사용 가능. 별도 설치 없이 학교 PC·태블릿·학생 스마트폰에서 즉시 사용.

## 6. 실현 가능성 (30점 — 최대 배점)

### 6-1. 이미 작동한다
첨부된 프로토타입은 5개 프리셋, 드래그 조작, 4개 표시 레이어, 온난화 실험, 퀴즈가 **모두 동작**하며 데스크톱·모바일에서 검증을 마쳤다(콘솔 오류 0).

### 6-2. 기술 스택 — 의도적으로 단순하게
- **순수 HTML + CSS + Vanilla JS + Canvas 2D.** 프레임워크·빌드·번들러 없음.
- **백엔드 0, 외부 API 0, API 키 0, DB 0.** → CORS·키 노출·서버 비용·다운타임 리스크가 **구조적으로 존재하지 않는다.**
- 모든 데이터(해안선·프리셋)는 JS에 내장 → `file://`로 더블클릭만 해도 실행. 심사위원이 어떤 환경에서 열어도 동작 보장.

### 6-3. 데이터 활용
"실제 기상 데이터 또는 데이터에서 파생된 모델·시나리오"라는 요건에 맞춰, **기상청 기상자료개방포털(data.kma.go.kr)·계절별 평년 기압배치**를 근거로 5개 프리셋의 기압계 위치·강도를 모델링했다. 본선 단계에서는 기상청 OpenAPI로 **실시간 지상 일기도(기압·기온)를 가져와 프리셋에 추가**하는 확장을 계획(정적 캐시 방식으로 실현 가능성 유지).

### 6-4. 배포
정적 파일이므로 GitHub Pages / Netlify / Vercel 무료 티어에 **드래그 한 번으로 배포**, 즉시 공개 URL 확보. 현장 라이브 데모 시 네트워크 장애에도 로컬 파일로 무중단 시연 가능.

## 8. 기대 효과

- **학생** : 외우던 기상 개념을 손으로 만들며 "왜?"를 스스로 설명하게 됨.
- **교사** : 설치·예산 없이 즉시 쓰는 차시별 수업 도구.
- **일반** : 기후위기를 추상이 아닌 "내가 만든 날씨의 변화"로 체감.

> 만들고, 바꾸고, 이해한다. 날씨 샌드박스는 기상학을 **명사(외울 지식)에서 동사(해보는 경험)로** 바꾼다.
