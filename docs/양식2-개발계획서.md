## 프로젝트명

**기후 식탁 (Climate Table) — 날씨가 바꾸는 우리 밥상**
부제: 이상기후가 농산물 가격(기후플레이션)에 미치는 영향을 직접 조작하며 배우는 인터랙티브 웹앱

## 개발 목적 및 필요성  ※주제 적합성

**한 줄 정의.** 폭염·가뭄·호우·한파·개화기 냉해 시나리오를 사용자가 직접 조작하면,
백엔드 회귀모델이 배추·무·사과·쌀·시금치·양파 6종의 가격을 실시간 예측한다.
"기후변화가 위험하다"는 추상적 경고를 "**내 장바구니·밥상이 얼마나 오르는가**"라는
체감으로 바꾼다.

**달성 목표.**
- 기상 → 작황 → 공급 → 가격으로 이어지는 인과를 사용자가 **직접 조작·검증**하게 한다.
- 기후플레이션·식량안보·기후적응 전략을 **능동 학습**시킨다.
- 설치·로그인·외부 의존성 없이 **URL 접속만으로 즉시 시연**되는 웹 서비스를 만든다.

**필요성(기존 기상·기후 교육의 한계).**
2024년 여름 폭염으로 배추 한 포기가 2만 원을 넘었고, 2023년 봄 개화기 냉해는 이듬해
'금사과'(사과값 폭등)를 불렀다. 이상기후는 더 이상 일기예보의 문제가 아니라 매일의
장바구니 물가, 곧 **기후플레이션**이다. 그러나 기존 기상·기후 교육 도구(태풍 진로,
기압·강수 시뮬레이터)는 모두 **대기 현상의 물리 메커니즘**에 머문다. 학습자는 "폭염이
왜 생기나"는 배우지만 "**그 폭염이 내 삶을 어떻게 바꾸는가**"는 배우지 못한다.
'기후 식탁'은 기상 데이터를 **사회·경제적 결과**(식량·물가)와 연결하는 교육 도구로,
기후위기를 '먼 빙하'가 아니라 '오늘 저녁 식탁'의 문제로 전환한다.

## 적용 기술 및 실현 구체성  ※실현 가능성

### 1) AI/데이터 기술과 활용 방식
- **예측 모델**: 작물별 **릿지(Ridge) 선형회귀**. 설계행렬 = [상수항, 기상 피처 6종, sin(월), cos(월)].
  정규방정식 (AᵀA + λI)x = Aᵀb 를 **가우스 소거**로 직접 해(λ=18로 다중공선성 억제).
  외부 ML 라이브러리 없이 **순수 파이썬**으로 구현 → 어디서나 재현·검증 가능.
- **피처**: 폭염일수·한파일수·호우일수·가뭄지수·개화기냉해·일조편차 + 계절성(월 sin/cos).
- **출력**: 예측가, 피처별 **기여액 분해**, 피어슨 상관, **설명력 R² 등급**(높음/보통/낮음), 시계열.
- **귀속 정확성**: 예측을 '같은 시기 평년 기상' 기준과 비교해 **계절 효과와 날씨 효과를 분리**.

### 2) 기술 스택 — 의도적으로 단순하게(실현 가능성 정조준)
| 영역 | 기술 | 비고 |
|---|---|---|
| 백엔드 | Python 표준 라이브러리 `http.server` | 외부 패키지·DB·API키 0 |
| 모델 | 순수 파이썬 릿지 회귀 | 외부 ML 라이브러리 0 |
| 프론트 | Vanilla JS(IIFE) + HTML5 + CSS | 프레임워크·번들러 0 |
| 시각화 | Canvas 2D 직접 렌더(차트·지도) | 차트 라이브러리 0 |
| 에셋 | Microsoft Fluent Emoji 3D(MIT) | 로컬 번들·이모지 폴백 |
| 검증 | `backend/test_api.py` 통합 테스트 | 전 엔드포인트·경계값·에러 |

`python backend/app.py` **한 줄로 기동**(백엔드가 프론트 정적 서빙). 설치 실패·CORS·키
노출·서버비용 리스크가 **구조적으로 없다.** 현재 풀스택이 동작하며 **통합 테스트 전부
통과**, 프론트 콘솔 에러 0. → 발표 심사 시 **심사위원 기기에서 URL 접속 즉시 시연** 가능.

## 체험 요소 및 학습 효과  ※체험·참여형 설계  ※학습 효과

### 체험 흐름 — 조작(Manipulate) → 예측(Predict) → 이해(Explain)
사용자 흐름은 **시작 → 진행 → 완료**의 양방향 상호작용으로 설계되어 있다.

**① 시뮬레이션 — 날씨를 직접 조작하면 가격이 실시간으로 바뀐다**

<img src="images/sim-compact.png" width="330" alt="시뮬레이션 탭 화면">

*▲ 2024 폭염·가뭄 프리셋 적용 시 배추 도매가 +78% 예측, 기여 요인·신뢰도(R²) 즉시 표시*

- 작물 6종 선택 → 폭염·호우·가뭄·한파·냉해 슬라이더 조절 또는 실제 사건 **프리셋**(2024 폭염, 2020 최장 장마, 2023 금사과, 한겨울 한파) 클릭.
- 입력 즉시(110ms 디바운스) **예측가·평년比%·기여 요인·해설·신뢰도(R²)·적응전략**이 갱신.
- 결과를 **지역별 영향 지도·과거 추이 차트·기상-가격 상관 막대**로 다각 시각화(모두 Canvas 직접 렌더).

**② 밥상 차리기 — 내 식탁이 이 날씨에 얼마인지 체감한다**

<img src="images/meal-compact.png" width="330" alt="밥상 차리기 탭 화면">

*▲ 음식을 식탁에 올리면 재료 원가(7,973원, +18%)와 외식가를 동시 계산. 날씨는 시뮬레이션 탭과 공유*

- 음식을 식탁에 올리면 **재료 원가**(집에서 해먹을 때)와 **외식가**(사먹을 때)를 동시 계산.
- 원자재(기후 작물)별 물가상승률과 **소비자 구매단위(포기·망·개·단·포대) 가격**을 함께 제시.
- 시뮬레이션 탭의 날씨 시나리오가 그대로 공유되어, "이 날씨면 우리 밥상이 얼마"가 즉시 보인다.

**③ 학습 퀴즈 — 풀고 즉시 해설로 학습한다**

<img src="images/quiz-compact.png" width="330" alt="학습 퀴즈 탭 화면">

*▲ 문항에 답하면 정답 여부와 근거 해설이 즉시 표시(국제 공동연구 PIK·ECB 출처 포함)*

- 개념·사례·대응·데이터·정책 **5개 분야 문항** + 모델로 직접 정답을 확인하는 **예측 챌린지**.
- 분야 선택·진행률·분야별 채점·결과 등급 제공, 정답/오답마다 **즉시 해설 피드백**.

### 학습 효과
- **인과 사슬의 체득**: 기상 → 작황 → 공급 → 가격이라는 보이지 않는 연결을 직접 만들며 이해.
- **데이터 리터러시**: 모델의 **설명력(R²)·신뢰도**를 함께 보여줘 "왜 쌀은 기상 영향이 작은가
  (정부 비축·수급관리)"까지 비판적으로 학습. 데이터로 사고하는 힘을 기른다.
- **시민·진로 교육**: 기후플레이션·식량안보는 과학·사회·경제·정책이 교차하는 주제로,
  교과 융합 수업과 진로 탐색에 적합. 기후위기 대응을 '공포'가 아니라 '이해와 행동'으로 전환.

## 창의성 및 차별성  ※아이디어 독창성

| 비교 대상 | 기존 한계 | 기후 식탁의 차별점 |
|---|---|---|
| 태풍·기압·강수 시뮬레이터 | 대기물리 메커니즘에 한정 | 기후의 **사회·경제적 결과**(식량·물가)를 다루는 접근 |
| 기후변화 일반 시각화 | 전 지구·장기·추상적 | **내 장바구니·밥상**이라는 즉각적·개인적 체감 |
| 단순 물가 차트 | 원인 설명 부재(일방향 읽기형) | 날씨를 **직접 조작**해 인과를 실험하는 양방향 구조 |

**핵심 독창성.** 미시(개별 작물 가격)와 거시(이상기후·기후위기)를 **회귀모델로 연결**하고,
사용자가 그 인과를 직접 조작·검증한다. 특히 **밥상 차리기**는 추상적 지표를 실제
식탁(원가 vs 외식, 구매단위 가격)으로 환산하는 **새로운 인터랙션**으로, 기후 데이터를
일상 의사결정과 잇는다. 의존성 0의 순수 구현으로 **누구나 즉시 재현·검증 가능**하다는
점도 교육 도구로서의 차별점이다.
