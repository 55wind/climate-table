# 수상 전략 — 경쟁작 분석 & 득점 플랜

## TL;DR (핵심 결론)
1. **본 공모전은 1회차(2026)** → 기존 수상 템플릿이 없다. 심사위원은 "정답 예시"가 없으므로 **루브릭을 정확히 때리는 작품 + 확실한 독창성**이 이긴다.
2. 인접 공모전(기상청 날씨 빅데이터 콘테스트)의 수상작은 모두 **기상 × 사회영역**(전력수요·119신고·열수요·화재·교통) 예측/분석이다. → 우리의 **기상 × 먹거리 물가(기후플레이션)**는 이 "기상으로 사회문제를 푼다"는 **검증된 승리 공식**에 정확히 올라탄다.
3. 공모전 공식 예시 6종은 **전부 대기물리 메커니즘**(태풍·기압·강수·기후·수치예보). 우리는 유일하게 **기후의 사회·경제적 결과**를 다룬다 → 독창성에서 빈틈을 정조준.
4. **기후플레이션은 트렌드는 뜨겁지만(보고서·기사 다수) "조작하며 배우는 인터랙티브 도구"는 아무도 안 만들었다** → 블루오션. (확인: 30년 CPI×날씨 데이터 분석 기사는 있어도, 시뮬레이터는 부재)

## 1. 경쟁 환경 분석

### 1-1. 본 공모전 (weatherhackathon.kr)
- 주최 기상청, **교육 콘텐츠** 목적. 결과물=브라우저 인터랙티브 도구.
- 배점: 주제적합성20 / **체험형25** / 학습효과10 / 독창성15 / **실현가능성30**.
- 무게중심 = 실현가능성(30)+체험형(25) = **55%**.

### 1-2. 인접 공모전 수상작 패턴 (날씨 빅데이터 콘테스트)
| 수상작 주제 | 패턴 |
|---|---|
| 기상→공동주택 전력수요 예측 | 기상 × 에너지 |
| 기상→119 신고건수 예측 | 기상 × 안전 |
| 기상→열수요 예측 | 기상 × 에너지 |
| 산림현상→화재 상관분석 | 기상 × 재난 |
| 기상→지하철 혼잡도 | 기상 × 교통 |
→ **공통점: 기상 데이터를 국민 체감 사회문제와 연결.** 우리(기상→밥상물가)는 정확히 이 계보. 게다가 **회귀모델로 실제 예측**까지 한다(분석 깊이 충족).

### 1-3. 공식 예시 6종 = 우리의 차별점
태풍 시뮬·기압맵·강수시뮬·기후체험·예보관체험·수치예보 — **모두 "현상의 원리"**. 우리는 **"현상의 결과(삶)"**. 카테고리 자체가 다르다 → 독창성 우위.

### 1-4. 참고 사이트로 본 심사위원 취향
공모전이 큐레이션한 레퍼런스: nullschool·Windy(시각미), **PhET·En-ROADS(조작=학습)**, Our World in Data(데이터 서사), NASA·ECMWF. → 심사위원이 좋아하는 것: **아름다운 인터랙션 + 직접 조작 학습 + 데이터 서사**. 우리 도구는 이 셋을 전부 차용(슬라이더 조작·실시간 차트·기여요인 분해).

### 1-5. 시장 공백 (블루오션)
기후플레이션: 농민신문 집중조명, ESG 트렌드, 정부 대응 보도 多 → **사회적 관심 최고조**. 그러나 시민이 **직접 날씨를 바꿔 가격을 실험**하는 교육 도구는 전무. → 신규성 + 시의성 동시 확보.

## 2. 우리의 포지셔닝 (한 문장)
> "기후위기를 빙하가 아니라 **오늘 저녁 식탁**으로 가져온, **기상 데이터를 직접 조작해 밥상물가를 실험**하는 유일한 교육 시뮬레이터."

## 3. 루브릭별 득점 전략 + 보강 액션

| 항목(배점) | 현재 강점 | 만점으로 가는 보강 |
|---|---|---|
| 주제적합성(20) | 실제 기상피처(폭염·가뭄·호우·냉해)+KAMIS 가격 | ✅ **교육과정 연계 명시**(통합과학 '기후변화', 사회 '경제'). 기상청 데이터 직접 사용 강조 |
| **체험형(25)** | 슬라이더 실시간 예측·기여요인 | 🔼 **프리셋=실제 사건 재현**(2024폭염→배추 2만원)으로 "와" 모먼트. 차트에 사건 마커 클릭 시 설명 |
| 학습효과(10) | 인과 사슬·신뢰도(R²) | 🔼 **퀴즈 결과 공유**, "오늘의 기후 식탁 지수" 같은 회수 장치 |
| 독창성(15) | 사회·경제 결과 = 유일 | ✅ "예시 6종에 없는 7번째 카테고리"임을 발표에서 명시 |
| **실현가능성(30)** | 풀스택 작동·18/18·의존성0·실데이터 파이프라인 | ✅ **즉시 실행 데모 + 자동검증 화면** 노출. 실데이터 교체 가능성 강조 |

## 4. 독창성 10-star 강화 (메모리에 남는 한 방)
- **"내 생일의 밥상" 모드**: 사용자가 특정 연·월을 고르면 그때 실제 날씨로 그 시절 밥상물가를 보여줌(개인화 서사). 
- **"기후플레이션 영수증"**: 시나리오 결과를 영수증 이미지로 만들어 SNS 공유 → 확산성(체험·학습 회수).
- **장바구니 모드**: 여러 작물을 담아 "이 폭염이면 우리집 장바구니 +N원" 합산 → 체감 극대화.
→ 이 중 1개만 추가해도 라이브 데모 임팩트가 크게 상승.

## 5. 리스크 & 방어 논리
| 예상 지적 | 방어 |
|---|---|
| "이게 기상·기후 교육 맞나?(경제 아닌가)" | 기상청 데이터로 **기상→작황→가격** 인과를 가르침. 통합과학·사회 융합. 기후위기 시민교육의 정공법 |
| "데이터가 실측인가" | 실제 도매가에 **보정+대조검증**(docs/검증) 완료, **실데이터 파이프라인**(KAMIS/기상청 API) 탑재 |
| "모델이 단순하지 않나" | R²·신뢰도 **투명 공개**, 정성적 인과 정확. 과신 방지 설계가 오히려 교육적 |

## 6. 라이브 데모 각본 (현장 승부수, 90초)
1. (5초) "배추 한 포기 2만원, 기억하시죠?" — 2024 폭염 프리셋 클릭 → 배추 3,950원/kg, +49% 즉시 표시.
2. (20초) 폭염 슬라이더를 더 올린다 → 가격·기여요인 실시간 상승. "기후가 밥상을 이렇게 바꿉니다."
3. (20초) 작물을 **쌀**로 변경 → 거의 안 변함. "쌀은 정부 비축으로 기상 영향이 작죠(R² 0.12). 데이터로 정책의 가치를 가르칩니다."
4. (20초) **사과+봄냉해** → 금사과 6,910원/kg 재현. "2023년 봄 서리가 2024년 금사과를 만들었습니다."
5. (15초) 해결방안 패널·퀴즈 → "이해에서 행동으로." 끝.
→ **실제 사건 재현 + 실시간 반응 + 정책 인사이트**의 3연타.
